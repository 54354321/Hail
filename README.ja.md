# 霰 · Graupel

[Hail](https://github.com/aistra0528/Hail) を基にした、並行インストール可能な Android アプリ凍結ツールです。原作者の帰属表示と [GPL-3.0 ライセンス](LICENSE)を維持しています。

- 独立したパッケージ名：`io.github.localbuild.graupel`
- システムのライト／ダーク設定に連動するランチャーアイコン
- ホーム・アプリ・設定の 3 タブ構成
- 設定の波紋効果と、行の直下に同じ幅で展開する選択メニュー

利用方法は[上流の説明](https://github.com/aistra0528/Hail/blob/main/README.ja.md)を参照してください。ビルドには JDK 21 と Android SDK 36 が必要です。手順、署名設定、ライセンスの詳細は [README](README.md)に記載しています。署名鍵や認証情報は含まれていません。
